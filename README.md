# buildmate-ai-adtc2026
Africa Deep Tech Challenge (ADTC) 2026 Laptop LLM track.
BuildMate AI

Offline AI Construction Inspection Assistant for Africa

Problem

Construction inspectors across Africa often work in locations where:

Internet is unavailable
Mobile data is expensive
Cloud AI APIs are unaffordable
Project information is confidential

BuildMate AI solves this by running an AI engineering assistant completely offline on an ordinary 8GB laptop.

Features
Offline AI
Local LLM
Voice transcription
Image evidence
PDF report generation
DOCX export
Engineering recommendations
Bridge inspections
Concrete inspections
Solar inspections
